## 0. 产品一句话

> **星澜（StarLive）**：阿维塔星环屏空闲壁纸工具。软件免费；内置少量示范；支持自定义导入；私人定制另售。  
> **定位**：Lyra 生态子项目——先服务「只换壁纸」用户，并保证 **可丝滑升级到 Lyra**（壁纸不丢、双装不抢、心智连续）。

**不做**：歌词特效、软件订阅、海量在线商城、凯迪 LivePaper 多屏主题包。  
**必做（升级）**：几何/文件名与 Lyra 同源；导流与 handoff 契约见 LYRA-UPGRADE。

## 3. StarLive 1.0 功能规格（用户可见）

### 3.1 信息架构（单页为主）

```text
┌──────────────────────────────────────────────┐
│  星澜 StarLive                    [关于]     │
│  ─────────────────────────────────────────   │
│  【星环预览条】  实时反映当前将上屏内容        │
│                                              │
│  [ 应用当前 ]  [ 导入图片 ]  [ 我要定制 ]     │
│  ─────────────────────────────────────────   │
│  示范壁纸（4）  ○ ○ ○ ○                      │
│  已导入        （当前文件名 / 自定义）        │
│  ─────────────────────────────────────────   │
│  空闲显示壁纸          [开]                   │
│  日夜                  自动 | 深 | 浅         │
│  （可选）本地轮播      [关]  间隔 n 分钟      │
│  ─────────────────────────────────────────   │
│  帮助规格 · 开源 · 歌词特效请用 Lyra          │
└──────────────────────────────────────────────┘
```

凯迪是「首页货架 + 详情成交」；星澜是「首页即完成」，无详情商城页。

### 3.2 行为规则

| 场景 | 行为 |
|------|------|
| 安装后首次打开 | 自动 seed 第 1 张 demo；提示「点应用当前看星环」 |
| 空闲显示=开 + 有图 | 请求 Cluster 自绘壁纸层 |
| 空闲显示=开 + 无图 | **不抢屏**，原厂星环可见 |
| 空闲显示=关 | 释放自绘表面 |
| 用户播歌 | **自动让出星环**（给原厂/Lyra/系统）；停播或暂停超过宽限后恢复壁纸；不渲染歌词 |
| 导入成功 | 预览刷新 + 可选自动应用 + Toast |
| 应用失败 | 人话：权限 / 屏不可达 / 图损坏 / 尺寸异常 |

### 3.3 导入约定

| 项 | 规格 |
|----|------|
| 推荐尺寸 | **2990 × 284** px（或 4032×284 且左侧 1042 为安全黑/空） |
| 格式 | JPG / PNG，建议 &lt; 2MB |
| Download 文件名（按序尝试） | `starlive_wallpaper.jpg` / `.png` · 兼容 `lyra_wallpaper.jpg` / `.png` · `cluster_wallpaper.jpg` |
| 成对日夜（可选） | `starlive_dark.jpg` + `starlive_light.jpg` |
| 裁切策略 | 见交互终稿：≈2990×284 精确；宽≥4032 条带优先 **x=1042 取右带**；否则居中 cover → 确认 → 写入 |

### 3.4 内置 4 张 demo（建议题材，可换图）

| ID | 方向 | 用途 |
|----|------|------|
| `demo_minimal_dark` | 深色简约 | 默认 seed |
| `demo_minimal_light` | 浅色简约 | 日间可读 |
| `demo_atmosphere` | 夜景/星尘氛围 | 晒图好看 |

## 7. 成功标准（1.0 验收）

1. 安装后 ≤3 步可把示范壁纸打上星环。  
2. 无相册时，按说明 push 到 Download 可导入成功。  
3. 非标准尺寸有预览确认，不静默糊一脸。  
4. 关「空闲显示」后原厂条可恢复可见。  
5. 「我要定制」能看清规格并找到联系方式。  
6. APK 体积显著小于塞满 catalog 的 Lyra 壁纸资源量级。  
7. 无任何「订阅后才能设置」逻辑。
