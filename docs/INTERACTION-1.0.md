## 1. 交互原则

| # | 原则 | 落地 |
|---|------|------|
| 1 | **首页即完成** | 不建「商城首页 + 详情」；主任务三键搞定 |
| 2 | **预览条 = 真相** | 条上显示的 = 即将/已经上星环的内容（WYSIWYG） |
| 3 | **先成功再折腾** | 首启路径优先「一键上示范」，导入/定制后置 |
| 4 | **车机触控** | 主按钮高度 ≥ 48–56dp；横屏优先；少键盘 |
| 5 | **失败说人话** | 禁止只弹「失败」；写清缺权限 / 无文件 / 屏不可达 |
| 6 | **付费不进主路径** | 定制是第三 CTA，永不挡「应用 / 导入」 |
| 7 | **可逆** | 关开关、恢复内置随时可退回原厂感 |
| 8 | **播歌让出** | 检测到歌曲播放中 → **自动释放星环**，不与系统歌词/Lyra/原厂争屏；停播后再按规则夺回 |
| 9 | **开机随空闲** | 「空闲显示壁纸=开」→ 开机/解锁后延迟重试上屏；=关 → 不自动占屏（方案 A） |
| 10 | **可升级到 Lyra** | 子项目引流；壁纸契约兼容；升级入口清晰；双装不恶性抢屏 → [LYRA-UPGRADE.md](./LYRA-UPGRADE.md) |

### 3.1 TopBar

| 元素 | 交互 |
|------|------|
| 标题「星澜」 | 不可点；副标 StarLive 小字或省略（窄屏只留星澜） |
| **状态胶囊** | 只读，不进入设置 |
| 关于 | 进 About |

**状态胶囊文案（互斥，按优先级从上到下只取第一条命中）**

| 优先级 | 条件 | 文案 | 视觉 |
|--------|------|------|------|
| 1 | 正在应用/导入/裁切写入 | **处理中…** | 中性脉冲 |
| 2 | 最近一次上屏意图失败且屏不可达（未过期） | **无法上屏** | 错误；副文案可点帮助 |
| 3 | 空闲开 + **判定为播放中**（已让出） | **播歌中 · 已让出** | 信息色（非错误） |
| 4 | 空闲关 | **已让出原厂** | 次要灰 |
| 5 | 空闲开 + 有有效选中 + 与实车不一致 / 待应用 / pending | **未上屏** | 警告色 |
| 6 | 空闲开 + 已成功上屏 + 未播放 + 预览与实车一致 | **已上屏** | 成功绿 |
| 7 | 其它（如仅 seed 未点过应用） | **未上屏** 或 待设置 | 次要 |

### 3.2 英雄预览条（Hero）

| 规则 | 说明 |
|------|------|
| 比例 | 模拟全条：左侧约 1/4 灰块表示表盘保留区，右侧为壁纸带 |
| 内容 | **始终显示「当前选中将应用的图」**（内置或自定义），不是「库缩略墙」 |
| 日夜 | 随「日夜模式」切换预览用 dark/light（若只有单图则不变） |
| 软边 | 预览需体现左侧 fade，避免用户以为硬切 |
| 点击 | **单击 = 等同「应用当前」**（加速路径；首次可 Toast「已应用到星环」） |
| 长按 | 无（1.0 不做） |

副文案一行（`heroSubtitle`），随状态变：

| 状态 | 副文案示例 |
|------|------------|
| 示范选中、未应用变更 | 已选「简约深」· 点应用看星环 |
| 与星环一致 | 星环与预览一致 |
| 导入待确认 | 新图待确认裁切 |
| 空闲关 | 已让出原厂星环 · 开「空闲显示」后可再上屏 |
| 播歌中让出 | 播歌中已让出星环 · 停播后自动恢复 |
| 上屏失败 | 点此查看原因（可点 → 错误 Sheet） |

### 3.3 三主按钮

| 按钮 | 层级 | 点击 |
|------|------|------|
| **应用当前** | Primary | 把当前选中源写入并尝试上屏 |
| **导入图片** | Secondary | 打开导入动作表（见 §5） |
| **我要定制** | Tertiary（描边或纯文字） | 打开 Custom 页/Sheet |

**禁用规则**

| 按钮 | 禁用当 |
|------|--------|
| 应用当前 | 处理中；或当前无有效图（极端） |
| 导入图片 | 处理中 |
| 我要定制 | 永不禁用 |

**加载态**：应用/导入中，Primary 变 spinner +「应用中…」，另两键 disable，防双击写屏。

### 3.4 示范 chips

| 规则 | 说明 |
|------|------|
| 数量 | 固定 4 |
| 交互 | 点选 = **仅切换预览与「当前选中」**，**默认不自动上屏**（避免误切实车） |
| 例外 | 设置项「点选示范后自动应用」**1.0 不做**；保持可控 |
| 选中态 | 描边/填充高亮 + 预览条立即换图 |
| 与自定义关系 | 选示范后，「当前来源」变为该示范名；自定义文件仍保留在磁盘，可再导入覆盖 |

### 3.5 当前来源行

| 元素 | 交互 |
|------|------|
| 文案 | `示范 · 简约深` / `自定义 · 文件名` |
| **恢复示范** | 二次确认（见 §7）→ 清除自定义 active，回到默认 demo，**预览变、不强制上屏**；可紧跟 Toast「已恢复 · 点应用同步到星环」 |

### 3.6 设置行

**空闲显示壁纸**（Switch，默认 **开**）

- 副文案（settings caption，一行）：**开启后占用星环显示壁纸，并在车辆启动后尝试自动恢复**
- **无**独立「开机自启」开关（开机方案 A = 本开关）

| 操作 | 结果 |
|------|------|
| 开→关 | 立即释放星环自绘；**可停轻量 FGS**；胶囊→已让出原厂；Toast「已让出原厂星环」；取消后续 boot 上屏调度 |
| 关→开 | **拉起轻量 FGS**（若未在）；若 **播放中** → 保持让出，胶囊「播歌中 · 已让出」，Toast「播歌结束后将自动上屏」并 `pendingApply`；若未播歌且有有效图 → 自动「应用当前」；若无图 → Toast「请先选择示范或导入」 |

**日夜模式**（三段 Segmented：自动 | 深 | 浅）

| 值 | 行为 |
|----|------|
| 自动 | 跟随系统/车机 UiMode；预览与上屏 bake 用对应 feather |
| 深 / 浅 | 强制；有 `*_dark/*_light` 则换图，单图则只调 edge bake |

切换日夜：**预览立即变**；若当前已是「已上屏」则 **自动静默重新应用**（无第二下确认，因用户在调观感）。

## 4. 关键用户路径

### 4.1 首次安装 → 第一次看见星环变了（黄金路径）

```text
安装打开
  → 隐私/权限：仅当即将读盘时再要（见 §6），首屏可先不弹
  → seed 默认「简约深」，预览已有图
  → 空闲显示 = 开
  → 轻提示条（可关，只显示一次）：
       「点「应用当前」或点上方预览条，把示范壁纸打到星环」
  → 用户点「应用当前」
  → 状态：处理中… → 已上屏
  → Toast：已应用到星环
  → 副文案：星环与预览一致
```

**成功判据**：用户不用进二级页、不用导入，≤2 次点击完成。

### 4.2 换一张示范

```text
点 chips「氛围」
  → 预览立刻换；来源=示范·氛围；胶囊若曾已上屏 → 变为「未上屏」
     （表示预览与实车不一致，促应用）
  → 点「应用当前」→ 已上屏
```

**不一致提示**：预览与实车不同时，Primary 可微光/角标「待应用」（不强制弹窗）。

### 4.3 导入自己的图

见 §5 完整分支。

### 4.4 暂时不要星澜

```text
关「空闲显示壁纸」
  → 让出原厂
  → 预览仍显示「若开启会上屏的图」（避免空白惊吓）
  → 副文案说明已让出
```

### 4.5 播歌时自动让出（已确认 · 审计默认）

```text
空闲显示 = 开
  → 判定「播放中」== true
  → 立即释放星环自绘（让出给原厂 / Lyra / 系统）
  → 胶囊：播歌中 · 已让出
  → 预览条：仍显示当前选中（可换图/导入）
  → 不弹阻塞框；首次让出可轻 Toast「播歌中已让出星环」（只一次）

退出「播放中」（见宽限）
  → 空闲仍开 + 有有效图
  → 自动上屏（含 pendingApply 的图）
  → 胶囊：已上屏
```

#### 4.5.1 什么叫「播放中」（定稿）

| 项 | 定稿 |
|----|------|
| 主信号 | **活跃 MediaSession 且 `isPlaying == true`**（车机 QQ/汽水/系统音乐等） |
| 补充 | NotificationListener 可读会话时作补充；**禁止 READ_LOGS 做歌词** |
| 电话 | **视为播放中 → 让出**（安全） |
| 导航 TTS / 无法区分的 playing | **宁可误让**（凡 isPlaying 则让出）；P0.5 再优化白名单 |
| 视频播放 isPlaying | **让出**（同媒体会话） |
| **未授予通知使用权 / 读不到会话** | **视为未播放** → **允许上壁纸**；设置区黄字：「建议开启通知使用权，以便播歌时自动让出星环」；**绝不**因未授权拒绝上屏 |
| 权限引导时机 | **不堵首启黄金路径**；在（a）用户第二次进入首页，或（b）设置里点黄字，或（c）首次发现「有媒体声但未让出」的弱提示时再引导 |

#### 4.5.2 宽限与用户操作

| 项 | 定稿 |
|----|------|
| **暂停** | 进入 **8s** 宽限；宽限内保持让出；仍暂停 → 夺回壁纸 |
| **切歌 / buffering / 短无 session** | **3s** 内保持让出，防闪 |
| 播歌中点「应用当前」 | Toast `toast_apply_deferred`；`pendingApply=true`（**持久化**） |
| 播歌中导入确认 | 保存 active + `pendingApply`，不上屏 |
| 恢复示范 | 清 `pendingApply` |
| 与 Lyra | 播歌中星澜不占屏；停播后若空闲开再上壁纸 |

#### 4.5.3 `pendingApply`（定稿）

| 项 | 定稿 |
|----|------|
| 存储 | **SharedPreferences 持久化**（杀进程/开机仍有效） |
| 含义 | 有一张「选中已保存、待空闲且未播放时上屏」的意图 |
| 消费 | 停播夺回成功或用户手动应用成功 → 清 flag |
| 开机 | 若 pending 且空闲开：未播放则上屏；播放中则让出等停播 |

**时间轴**

```text
壁纸上屏 ──► 播放中 ──► 让出 ──► 切歌空隙(<3s)仍让出
                         │
                    暂停 ──8s──► 仍暂停则夺回
                         │
                    停止 ──► 夺回（含 pending 图）
```

### 4.6 定制转化

```text
点「我要定制」
  → Custom：看规格 + 示例说明 + 复制微信号 / 看二维码
  → 不强制填表；减少车机输入
```

## 5. 导入交互（核心）

### 5.1 点「导入图片」→ 动作表（Action Sheet）

```text
导入壁纸
  ① 从相册/文件选择    → 系统选择器
  ② 从 Download 导入   → 扫描约定文件名
  ③ 查看文件名说明     → 短说明或进 Spec 锚点
  取消
```

车机无图库时：① 失败或不可用 → 自动高亮 ②，并 Toast 引导。

### 5.2 Download 扫描顺序

```text
/sdcard/Download 与 /storage/emulated/0/Download（及 Pictures 兼容）:

1. starlive_wallpaper.jpg / .png
2. starlive_dark.jpg + starlive_light.jpg（成对优先于单文件）
3. lyra_wallpaper.jpg / .png（兼容）
4. cluster_wallpaper.jpg
```

- 找到 **一对** dark/light → 进入确认（预览可切换深浅）  
- 找到单文件 → 进入确认  
- 都没有 → 错误 Sheet（§7.2）

### 5.3 导入确认页 / 面板（ImportConfirm）

**何时出现**

| 情况 | 是否进确认页 |
|------|----------------|
| 尺寸正好 2990×284（或可接受容差 ±2px） | **可跳过确认**，直接写入并询问是否应用；或仍进确认仅一键（产品选：**容差内仍进确认，但主按钮为「应用」一步完成**） |
| 比例/尺寸不符 | **必须确认裁切** |
| 文件损坏 | 不进确认，直接错误 |

**1.0 定稿：凡导入都进确认页**（统一心智；容差内裁切框=全图）。避免「有时弹有时不弹」。

**确认页结构**

```text
┌─────────────────────────────────────┐
│  确认壁纸                      [×]  │
│  ─────────────────────────────────  │
│  预览条（裁切结果 + 软边预览）       │
│  原图信息：4032×500 · 将裁为 2990×284│
│                                     │
│  （可选）深 | 浅  若成对导入才显示   │
│                                     │
│  [ 取消 ]              [ 应用上屏 ] │
└─────────────────────────────────────┘
```

| 操作 | 行为 |
|------|------|
| 取消 | 丢弃本次导入会话，不改当前 active |
| 应用上屏 | 写入 active → **若未播歌**则上屏；**若播歌中**则只保存 + pendingApply，Toast 说明停播后上屏 → 回首页；来源=自定义·文件名 |
| 仅保存不关 | **1.0 不做**第二按钮，减少选择瘫痪（应用=保存+上屏；播歌时降级为保存待上屏） |

**裁切规则（定稿 · 对用户可见一句）**  
「将裁为星环壁纸比例，左侧表盘区不放贴图。」

**裁切算法（实现死约定）**

| 原图 | 策略 |
|------|------|
| 宽高与 2990×284 差 ≤2px | 视为精确，可只做 soft-edge bake |
| **宽 ≥ 4032 且高大致为条带**（高在 200–400 或比例接近 4032:284） | **优先从 x=1042 取宽 2990、高居中取 284**（对齐表盘保留区）；若高不足则 cover |
| 其它任意比例 | **居中 cover** 到 2990×284 |
| 解码 | 采样，避免整图 OOM；单边过长先 scale |

确认页展示：`原图 W×H · 策略说明（居中裁切 / 按星环右带裁切）`。

不提供 1.0 自由拖拽裁切框；P1 再考虑。

### 5.4 导入成功回首页

- 预览=新图  
- 胶囊=已上屏（若上屏成功）  
- Toast：壁纸已应用  
- chips 示范高亮清除（或保持视觉「未选示范」）

## 6. 权限、FGS 与首次

### 6.1 权限节奏

| 时机 | 策略 |
|------|------|
| 冷启动 | **不**弹存储 / **不**弹通知使用权 / **不**弹电池优化 |
| 点导入 ① 或 ② | 再请求读存储/媒体；拒绝 → 错误 Sheet |
| 上屏 | 不额外要无关权限；失败 →「无法上屏」 |
| 通知使用权 | 见 §4.5.1，**不堵黄金路径** |
| 电池优化 / 自启动 | 仅 **规格/关于/帮助** 链出系统页；不强制 |

无登录、无设备码绑定。安装后 **请至少打开一次 App**（帮助写明，利于自启）。

### 6.2 轻量前台服务（定稿）

| 项 | 定稿 |
|----|------|

## 14. 验收剧本（交互）

1. **冷启 App**：见预览有图，点应用 → 已上屏，无多余权限弹窗。  
2. **切 chip**：预览变、未上屏 → 应用 → 一致。  
3. **关空闲**：已让出；FGS 停；再开自动上屏（未播歌时）。  
4. **Download 无文件**：错误含文件名。  
5. **非标尺寸 / 4032 宽图导入**：确认页策略文案正确 → 应用成功。  
6. **恢复示范**：确认 → 预览回 demo → 需再应用；pending 清除。  
7. **定制 / 关于**：微信号、免责、隐私摘要可见。  
8. **播歌让出**：胶囊「播歌中 · 已让出」；暂停 >8s 或停止后恢复。  
9. **播歌中应用 / 导入**：deferred Toast；停播后自动上屏；杀进程再开仍 pending 生效。  
10. **无通知使用权**：仍可上壁纸；有黄字引导。  
11. **车辆冷启动**（空闲开、未播歌）：20s 内尽力恢复壁纸，**无弹窗**。  
12. **车辆冷启动**（空闲开、已播歌）：不占屏；停播后上屏。  
13. **空闲关冷启动**：不占屏。
