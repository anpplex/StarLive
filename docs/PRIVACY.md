# 隐私说明（星澜 StarLive）

最后更新：2026-08-03

## 我们收集什么

星澜 **默认不强制联网**，无账号体系。

| 数据 | 用途 | 是否上传 |
|------|------|----------|
| 你选择的壁纸图片 | 本地裁切、显示到星环 | **否**（仅本机） |
| 空闲开关 / 日夜 / 当前壁纸偏好 | 本地设置 | **否** |
| 媒体播放状态（是否在播） | **仅**用于播歌时让出星环 | **否**；不做歌词分析 |
| 通知使用权（若你开启） | 辅助读取 MediaSession | 系统权限；我们不上传内容 |

## 权限说明

| 权限 | 原因 |
|------|------|
| 读取图片/存储 | 导入壁纸 |
| 前台服务 / 通知 | 保持空闲壁纸与播歌让出逻辑 |
| 开机广播 | 空闲显示开启时尝试恢复壁纸 |
| 通知使用权（可选） | 更可靠地检测是否播歌 |

拒绝可选权限时：仍可手动应用壁纸；播歌让出可能不准。

## 与 Lyra

升级到 Lyra 时，你可按说明导出或通过 Download 约定文件迁移壁纸。Lyra 的授权与隐私以其产品说明为准。
