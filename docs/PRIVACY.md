# 隐私说明（星澜 StarLive）

最后更新：2026-08-03

## 我们收集什么

星澜 **默认不强制联网**，无账号体系。

| 数据 | 用途 | 是否上传 |
|------|------|----------|
| 你选择的壁纸图片 | 本地裁切、显示到星环 | **否**（仅本机） |
| 空闲开关 / 日夜 / 当前壁纸偏好 | 本地设置 | **否** |
| 媒体播放状态（是否在播） | **仅**用于播歌时让出星环 | **否**；不做歌词分析 |
| 通知使用权（若你开启） | 辅助读取 MediaSession | 系统权限；我们不上传内容 |
| **兑换码 + 本机 device_id**（仅当你使用「兑换主题」） | 服务端核销、一码一设备、下发主题包 | **是**（到 LicenseHub / 配置的兑换 API；无账号密码） |
| 主题包 zip | 下载到本机后安装进图库 | 下载流量；安装后本地使用 |
| **检查更新**（仅当你点「关于 → 检查更新」） | 读取 GitHub Releases 最新 tag | **是**（api.github.com；无账号） |

不使用兑换 / 检查更新时，App **仍可不强制联网** 完成示范 / 导入 / 上屏。

## 权限说明

| 权限 | 原因 |
|------|------|
| 读取图片/存储 | 导入壁纸 |
| 网络（兑换时） | 兑换码核销与主题包下载 |
| 前台服务 / 通知 | 保持空闲壁纸与播歌让出逻辑 |
| 开机广播 | 空闲显示开启时尝试恢复壁纸 |
| 通知使用权（可选） | 更可靠地检测是否播歌 |

拒绝可选权限时：仍可手动应用壁纸；播歌让出可能不准。

## 与 Lyra

升级到 Lyra 时，你可按说明导出或通过 Download 约定文件迁移壁纸。Lyra 的授权与隐私以其产品说明为准。
