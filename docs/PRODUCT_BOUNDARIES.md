# 产品边界

## 可提供的能力

| 能力 | 前提 |
|------|------|
| 星环空闲壁纸显示 | 车机允许第三方启动 Cluster 显示屏 |
| 内置壁纸、导入与裁切确认 | 按需授予存储或选图权限 |
| 关闭星环壁纸后恢复原厂显示 | 用户主动关闭 |
| 播放音乐时自动让出星环 | 可读取媒体会话；未授权时壁纸仍可用，让出可能失效 |
| 开机后尝试恢复显示 | 已开启星环壁纸，且系统未强制结束进程；不保证全车型 100% |
| 与 Lyra 共用壁纸规格 | 几何与文件名兼容，见 [LYRA-UPGRADE.md](./LYRA-UPGRADE.md) |

## 不提供的能力

| 能力 | 说明 |
|------|------|
| 系统级 Wallpaper 常驻 | 采用旁路 Activity 自绘 |
| 歌词与播歌视觉特效 | 由 Lyra 提供 |
| 软件订阅或在线商城 | 当前产品形态不包含 |
| 与官方星环像素级一致 | 无系统特权 |
| 与 Lyra 同时占用空闲星环且零冲突 | 建议仅由一端接管；可开启「Lyra 优先」 |
| 全部车型开机自启 | 依赖厂商白名单，存在差异 |

## 与 Lyra 的分工

- **星澜**：空闲壁纸  
- **Lyra**：播歌特效与商业授权等完整能力  
- 升级与互通约定见 [LYRA-UPGRADE.md](./LYRA-UPGRADE.md)
