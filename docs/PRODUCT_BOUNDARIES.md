# 产品边界（P0）

## 可承诺（条件满足时）

| 能力 | 条件 |
|------|------|
| 星环空闲壁纸自绘 | Cluster Display 对第三方可 launch |
| 4 demo + 导入 + 裁切确认 | 存储/选图权限按需 |
| 空闲开关让出原厂 | 用户操作 |
| 播歌自动让出 | MediaSession 可读；未授权时仍可上壁纸（让出可能失效） |
| 开机尽力恢复 | 空闲显示=开；厂商不杀后台；不保证 100% |
| 升级到 Lyra 的地基 | 几何/文件名兼容；引导与 handoff 契约 |

## 不可承诺

| 能力 | 原因 |
|------|------|
| 系统级 Wallpaper 常驻 | 旁路 Activity 自绘 |
| 歌词特效 | 属 Lyra |
| 软件订阅/商城 | 方案 A 不做 |
| 与官方星环像素级一致 | 无系统特权 |
| 双装时永远零冲突 | 尽力让路；用户应只开一边接管 |
| 全车型开机自启 | 厂商白名单差异 |

## 与 Lyra

- 星澜 = 子项目 / 引流；主能力空闲壁纸。  
- 播歌特效、商业授权 = Lyra。  
- 升级：见 [LYRA-UPGRADE.md](./LYRA-UPGRADE.md)。
