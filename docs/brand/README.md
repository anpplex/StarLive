# StarLive 品牌 · 星环（Gargantua）

**蓝本**：《星际穿越》卡冈图雅（Gargantua）  
**关键词**：**星环** — 发光吸积盘环绕暗虚空，而非地球大气/贴地粒子。

## 识别结构

| 层 | 含义 |
|----|------|
| 暗核 | 视界 / 深空虚空 |
| 光子环 | 紧贴视界的亮细环 |
| **吸积星环** | 主识别：倾斜椭圆光环，右缘更亮（多普勒暗示） |
| 透镜弧 | 盘面远端绕过黑洞上方的光弧 |
| 星尘 | 仅附着在星环带上 |
